숏리드 유전체

shortWGS

Illumina 세균 유전체 분석. 균종, MLST, 내성 유전자, 플라스미드를 확인하고 HTML·CSV 결과를 생성합니다.

참조 DB 준비 ↓

STATUS: TESTED IN CORE2 WORKSTATION

분석 흐름

Prefilter→ fastp→ Kraken2→ SRST2 (MLST/ARG/Plasmid)→ TETyper→ MultiQC + Summary

컨테이너 빌드

cd shortWGS
docker build --network=host -t shortwgs .

실행 방법

./shortWGS/Go_shortWGS.sh \
  -i /path/to/fastq \
  -o /path/to/output \
  -d /path/to/WGS_DB2 \
  -k /path/to/kraken2_db \
  -r /path/to/GoWGS \
  -K

실행 예시

Go_shortWGS.sh \
  -i shortWGS/20261101_WGS_HKP \
  -o shortWGS/20261101_WGS_HKP_out \
  -d /media/uhlemann/core4/DB/WGS_DB2 \
  -k /media/uhlemann/core4/DB/kraken2DB/k2_pluspfp_16gb_20241228 \
  -r $CAULAB_PIPELINES/GoWGS \
  -K

참조 DB 준비

DB / 참조 파일저장 위치 · 실행 옵션
CARD · PlasmidFinder (SRST2 형식)WGS_DB/CARD/*.fasta, WGS_DB/PlasmidFinder/*.fasta
종별 MLSTWGS_DB/MLST/e_coli/ 등: allele FASTA + profile 표
TETyperWGS_DB/tetyper/: Tn4401b-1.fasta, struct_profiles.txt, snp_profiles.txt
Kraken2KBracken과 같은 DB를 -k로 지정
WGS_DB="/path/to/WGS_DB2"
mkdir -p "$WGS_DB/CARD" "$WGS_DB/PlasmidFinder" "$WGS_DB/tetyper"
curl -fL https://raw.githubusercontent.com/katholt/srst2/master/data/CARD_v3.0.8_SRST2.fasta -o "$WGS_DB/CARD/CARD_v3.0.8_SRST2.fasta"
curl -fL https://raw.githubusercontent.com/katholt/srst2/master/data/PlasmidFinder.fasta -o "$WGS_DB/PlasmidFinder/PlasmidFinder.fasta"
for file in Tn4401b-1.fasta struct_profiles.txt snp_profiles.txt; do
  curl -fL "https://raw.githubusercontent.com/aesheppard/TETyper/master/$file" -o "$WGS_DB/tetyper/$file"
done

위 CARD와 PlasmidFinder 파일은 SRST2 배포본에 포함된 기존 버전입니다. 최신 DB가 필요하면 원본 서열을 SRST2 형식으로 변환해야 합니다. 각 폴더에 사용할 FASTA 하나만 둡니다. 파이프라인은 정렬상 첫 파일을 선택합니다.

mkdir -p "$WGS_DB/MLST/e_coli"
cd "$WGS_DB/MLST/e_coli"
# SRST2가 설치된 환경에서 실행
getmlst.py --species "Escherichia coli#1"

MLST는 SRST2의 getmlst.py 안내 ↗에 따라 종·scheme별로 받습니다. 생성된 allele FASTA와 profiles_csv 표를 함께 보관합니다. 다른 종의 폴더 이름은 워크플로의 종 코드에 맞춥니다. 실행 시 전체 폴더는 -d "$WGS_DB", Kraken2는 -k /path/to/kraken2_db로 지정합니다.
