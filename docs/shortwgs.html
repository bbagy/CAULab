Illumina sequences

shortWGS

Illumina Bacterial Genome · 균종 · MLST · 내성 유전자 · 플라스미드 · HTML / CSV

설치 및 DB 준비 →

실행 환경: Docker and Apptainer

분석 흐름

Prefilter→ fastp→ Kraken2→ SRST2 (MLST/ARG/Plasmid)→ TETyper→ MultiQC + Summary

실행 방법

새 터미널 설정: source "$HOME/kpark-pipelines/kpark.env"

Go_shortWGS.sh \
  -i /path/to/fastq \
  -o /path/to/output \
  -d /path/to/WGS_DB2 \
  -k /path/to/kraken2_db \
  -K

실행 예시

Go_shortWGS.sh \
  -i shortWGS/20261001_WGS_HKP \
  -o shortWGS/20261001_WGS_HKP_out \
  -d "$HOME/kpark-db/shortWGS" \
  -k "$HOME/kpark-db/kraken2/k2_pluspfp_16gb_latest" \
  -K

옵션

옵션설명
-r보고서 폴더 지정(선택) · 기본값: 설치된 shortWGS 폴더
-n실행 계획 확인
-K오류 발생 시 나머지 샘플 계속 실행
-cSnakemake CPU 수
-m사용자 지정 Docker 이미지 태그
