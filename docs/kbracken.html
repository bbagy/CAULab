KBracken

미생물 분류와 풍부도 추정. Kraken2·Bracken 결과를 샘플별로 계산하고 MPA 형식의 표로 통합합니다.

설치 및 DB 준비 →

STATUS: AVAILABLE — TESTED IN CORE4 WORKSTATION

분석 흐름

Prefilter→ Kraken2→ MPA report→ merge_mpa_tables→ Bracken (opt)→ bracken_to_mpa→ fill_bracken_taxonomy

실행 방법

Go_KBracken.sh \
  -i /path/to/fastq_dir \
  -o KBracken_out \
  -d /path/to/kraken2_db \
  -c 8 \
  -j 4 \
  -K

입력 파일 이름

ASB_1_R1.fastq.gz / ASB_1_R2.fastq.gz -> sample ASB_1
ASB_2_R1.fastq.gz / ASB_2_R2.fastq.gz -> sample ASB_2
S1_1.fastq.gz and S1_2.fastq.gz stay separate single-end samples

Paired-end inference requires explicit R1/R2 or forward/reverse tokens.
