KBracken

Kraken2 / Bracken · 미생물 분류 · 풍부도 추정 · MPA 표 통합

설치 및 DB 준비 →

실행 환경: Docker and Apptainer

분석 흐름

Prefilter→ Kraken2→ MPA report→ merge_mpa_tables→ Bracken (opt)→ bracken_to_mpa→ fill_bracken_taxonomy

실행 방법

Go_KBracken.sh \
  -i /path/to/fastq_dir \
  -o KBracken_out \
  -d /path/to/kraken2_db \
  -c 8 \
  -j 4 \
  -K

입력 파일 이름

ASB_1_R1.fastq.gz / ASB_1_R2.fastq.gz -> 샘플 ASB_1
ASB_2_R1.fastq.gz / ASB_2_R2.fastq.gz -> 샘플 ASB_2
# S1_1.fastq.gz와 S1_2.fastq.gz: 각각 독립된 single-end 샘플

Paired-end 파일명: R1/R2 또는 forward/reverse 구분 필수
