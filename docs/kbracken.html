KBracken

미생물 분류와 풍부도 추정. Kraken2·Bracken 결과를 샘플별로 계산하고 MPA 형식의 표로 통합합니다.

참조 DB 준비 ↓

STATUS: AVAILABLE — TESTED IN CORE4 WORKSTATION

분석 흐름

Prefilter→ Kraken2→ MPA report→ merge_mpa_tables→ Bracken (opt)→ bracken_to_mpa→ fill_bracken_taxonomy

설치 경로

heekuk_path/
|-- Go_KBracken.sh
|-- Go_KBracken.smk
|-- scripts/
|   |-- bracken_to_mpa.py
|   |-- fill_bracken_taxonomy.py
|   |-- kraken_masterlog.py
|   `-- merge_mpa_tables.py
`-- docker/KBracken/
    `-- Dockerfile

컨테이너 빌드

cd $CAULAB_PIPELINES/KBracken
docker build --network=host -t kbracken:caulab .

실행 방법

Go_KBracken.sh \
  -i /path/to/fastq_dir \
  -o KBracken_out \
  -d /path/to/kraken2_db \
  -c 8 \
  -j 4 \
  -K

입력 파일 이름

ASB_1_R1.fastq.gz / ASB_1_R2.fastq.gz -> sample ASB_1
ASB_2_R1.fastq.gz / ASB_2_R2.fastq.gz -> sample ASB_2
S1_1.fastq.gz and S1_2.fastq.gz stay separate single-end samples

Paired-end inference requires explicit R1/R2 or forward/reverse tokens.

참조 DB 준비

DB / 참조 파일저장 위치 · 실행 옵션
Kraken2 PlusPFP 16GB + Bracken$DB_ROOT/kraken2/k2_pluspfp_16gb_latest → -d
source "$HOME/caulab-pipelines/caulab.env"
DB_ROOT="/path/to/DB"
bash "$CAULAB_PIPELINES/download_databases.sh" --db-root "$DB_ROOT" --tools kraken2 --threads 8 --bracken-read-len 100
source "$CAULAB_PIPELINES/config/lab_paths.sh"

Docker 이미지 kbracken:caulab를 먼저 빌드합니다. 위 명령은 Kraken2 DB를 받고 100 bp용 Bracken 파일을 만듭니다. --bracken-read-len은 분석에 사용할 리드 길이에 맞추며, 현재 워크플로 기본값은 100 bp이며, 길이를 바꾸면 bracken_read_len 설정도 함께 변경합니다. 폴더 안에 hash.k2d, opts.k2d, taxo.k2d와 해당 길이의 Bracken 파일이 있어야 합니다.
