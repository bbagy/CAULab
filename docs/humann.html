Humannake

샷건 메타유전체 기능 분석. HUMAnN3·MetaPhlAn4로 유전자군, 대사경로, KEGG orthology 결과를 생성합니다.

참조 DB 준비 ↓

STATUS: AVAILABLE — TESTED IN CORE4 WORKSTATION

분석 흐름

Prefilter + R1/R2 merge→ HUMAnN3 per-sample→ MetaPhlAn4 bug list→ join_tables→ renorm CPM→ regroup UniRef90_rxn→ MUSiCC (opt)→ rename KEGG-orthology→ stratified split

컨테이너 빌드

cd Humann
docker build --network=host -t humann:caulab .

실행 방법

./Humann/Go_Humannake.sh \
  -i /path/to/host_filtered_fastq \
  -o humann_run \
  -n /path/to/chocophlan \
  -p /path/to/uniref \
  -b /path/to/metaphlan_db \
  -I mpa_vJan25_CHOCOPhlAnSGB_202503 \
  -c 8 -j 4 -t 4 \
  --run-musicc \
  -K

실행 예시

Go_Humannake.sh \
  -i Humann/20261101_MG_HKP_nohuman \
  -o Humann/20261101_MG_HKP_humann_out \

  -I mpa_vJan25_CHOCOPhlAnSGB_202503 \
  -s "$CAULAB_PIPELINES/Humann" \
  -c 8 -j 4 -t 4 \
  --run-musicc \
  -K

참고 사항

  • Recommended MetaPhlAn input: -b <dir> + -I <index_basename>; .pkl shortcut auto-resolves for legacy use.
  • Paired _R1 / _R2 (including _nohuman variants) are merged per sample into 7_intermediate/<sample>.merged.fastq.gz before HUMAnN runs.
  • Per-sample .humann.done markers allow safe resume after interruption.
  • --run-musicc enables MUSiCC correction on the regrouped KO table.

참조 DB 준비

DB / 참조 파일저장 위치 · 실행 옵션
ChocoPhlAn$DB_ROOT/humann/chocophlan → -n
UniRef90 DIAMOND$DB_ROOT/humann/uniref90_diamond → -p
MetaPhlAn4$DB_ROOT/humann/metaphlan4 → -b, 인덱스 이름 → -I

CAULab이 $HOME/caulab-pipelines에 설치되어 있고 Docker가 실행 중이면 아래 명령을 터미널에 복사해 실행할 수 있습니다. DB는 $HOME/caulab-db에 저장됩니다. 다른 디스크에 받으려면 DB_ROOT 한 줄을 실제 저장 경로로 바꿉니다. 다운로드는 대용량이므로 저장할 디스크의 여유 공간을 먼저 확인하세요. 앞 단계에서 오류가 나면 다음 단계로 넘어가지 않습니다.

# 1. 기본 경로에 설치된 CAULab 환경 불러오기
source "$HOME/caulab-pipelines/caulab.env"

# 2. Docker를 실행한 상태에서 이미지 준비 (이미 있으면 생략)
docker build -t humann:caulab "$CAULAB_PIPELINES/Humann"

# 3. DB 저장 위치: 홈 폴더의 caulab-db
DB_ROOT="$HOME/caulab-db"

# 4. ChocoPhlAn, UniRef90, MetaPhlAn DB 다운로드
bash "$CAULAB_PIPELINES/download_databases.sh" --db-root "$DB_ROOT" --tools humann --humann-uniref uniref90_diamond

# 5. 완료 후 DB 경로 설정 불러오기
source "$CAULAB_PIPELINES/config/lab_paths.sh"

# 6. 받은 MetaPhlAn 인덱스 이름 확인 (추가 다운로드 아님)
find "$DB_ROOT/humann/metaphlan4" -maxdepth 1 -name "*.pkl"

Docker 이미지 humann:caulab를 먼저 빌드합니다. 이 파이프라인의 UniRef90 후처리에 맞춰 UniRef90을 받습니다. 다운로드한 .pkl 파일명에서 확장자를 뺀 값을 -I에 지정하세요. 기존 예시의 인덱스 이름과 새로 받은 DB 이름이 다르면 새 이름으로 바꿉니다. 재현 분석에는 동일한 DB 버전을 사용합니다.
