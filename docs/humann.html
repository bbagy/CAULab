Metagenome

Humannake

Metagenome 기능 분석 · HUMAnN3 / MetaPhlAn4 · 유전자군 · 대사경로 · KEGG orthology

설치 및 DB 준비 →

실행 환경: Docker and Apptainer

분석 흐름

Prefilter + R1/R2 merge→ HUMAnN3 per-sample→ MetaPhlAn4 bug list→ join_tables→ renorm CPM→ regroup KO→ MUSiCC (opt)→ rename KEGG-orthology→ stratified split

실행 방법

새 터미널 설정: source "$HOME/kpark-pipelines/kpark.env"

Go_Humannake.sh \
  -i /path/to/host_filtered_fastq \
  -o humann_run \
  -n /path/to/chocophlan \
  -p /path/to/uniref \
  -u /path/to/utility_mapping \
  -b /path/to/metaphlan_db \
  -I mpa_vJun23_CHOCOPhlAnSGB_202307 \
  -c 8 -j 4 -t 4 \
  -K

실행 예시

Go_Humannake.sh \
  -i Humann/20261001_MG_HKP_nohuman \
  -o Humann/20261001_MG_HKP_humann_out \
  -n "$HOME/kpark-db/humann/chocophlan" \
  -p "$HOME/kpark-db/humann/uniref90_diamond" \
  -u "$HOME/kpark-db/humann/utility_mapping" \
  -b "$HOME/kpark-db/humann/metaphlan4" \
  -I mpa_vJun23_CHOCOPhlAnSGB_202307 \
  -s "$KPARK_PIPELINES/Humann" \
  -c 8 -j 4 -t 4 \
  -K

옵션

옵션설명
-i숙주 제거 FASTQ 입력 폴더
-o출력 폴더
-uKO 매핑 DB 폴더 · 기본값: KPARK_HUMANN_UTILITY
-nHUMAnN3 핵산 DB (chocophlan)
-pHUMAnN3 단백질 DB (uniref)
-bMetaPhlAn4 DB 폴더 또는 .pkl
-IMetaPhlAn4 인덱스 이름
-c / -j / -tSnakemake CPU / 동시 작업 / HUMAnN 스레드
-x실행 계획 확인
-K오류 발생 시 나머지 샘플 계속 실행
--run-musiccMUSiCC 보정 사용
--skip-gene-norm유전자군 정규화 생략
--skip-path-split균종별 / 전체 결과 분리 생략

참고 사항

  • MetaPhlAn DB: -b DB_DIR · 인덱스: -I INDEX_NAME
  • R1/R2 병합: 7_intermediate/<sample>.merged.fastq.gz
  • 재시작 체크포인트: 샘플별 .humann.done
  • --run-musicc: KO 표 MUSiCC 보정
