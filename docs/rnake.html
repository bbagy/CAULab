RNake

세균 RNA-seq 분석. 리드 트리밍, 참조 유전체 매핑, 유전자별 카운트를 수행하고 샘플별 카운트 표를 통합합니다.

참조 DB 준비 ↓

STATUS: AVAILABLE — TESTED IN CORE3 WORKSTATION

분석 흐름

Prefilter→ Trim→ Bowtie2 Mapping→ Count Matrix→ Merged Table

컨테이너 빌드

cd RNake
docker build -t rnake:1.0 .

실행 방법

./RNake/Go_Rnake.sh \
  -i /path/to/reads \
  -o project_name \
  -g /path/to/genome.fna \
  -a /path/to/annotation.gff \
  -c 8 \
  -K

실행 예시

Go_Rnake.sh \
  -i RNake/20261101_RNA_HKP \
  -o RNake/20261101_RNA_HKP_out \
  -g /media/uhlemann/Core3_V2/REF/ecoli.fna \
  -a /media/uhlemann/Core3_V2/REF/ecoli.gff \
  -s "$CAULAB_PIPELINES/RNake" \
  -K

참조 DB 준비

DB / 참조 파일저장 위치 · 실행 옵션
참조 유전체 FASTA-g /path/to/genomic.fna
같은 assembly의 GFF3-a /path/to/genomic.gff
# NCBI Datasets CLI가 설치된 환경에서 실행 (E. coli K-12 예시)
datasets download genome accession GCF_000005845.2 --include genome,gff3 --filename reference.zip
unzip reference.zip -d reference
find reference/ncbi_dataset/data -type f \( -name "*.fna" -o -name "*.gff" \)

분석 대상 균주의 assembly accession으로 바꿔 받습니다. 압축을 풀고 FASTA와 GFF 경로를 각각 -g, -a에 지정합니다. 두 파일은 동일한 assembly 버전이어야 합니다. Bowtie2 인덱스는 파이프라인이 생성합니다. CLI 없이 NCBI Datasets 웹에서도 같은 파일을 받을 수 있습니다.
