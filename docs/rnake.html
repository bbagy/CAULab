RNake

Bacterial RNA-seq · 트리밍 · 참조 유전체 매핑 · 유전자 카운트 · 샘플별 표 통합

설치 및 DB 준비 →

실행 환경: Docker and Apptainer

분석 흐름

Prefilter→ Trim→ Bowtie2 Mapping→ Count Matrix→ Merged Table

실행 방법

분석 데이터와 결과는 /data/projects에 저장합니다. 예제 실행 전 프로젝트 폴더를 준비하세요.

source /data/kpark-pipelines/kpark.env
mkdir -p /data/projects/ProjectA
cd /data/projects/ProjectA

새 터미널 설정: source "/data/kpark-pipelines/kpark.env"

Go_Rnake.sh \
  -i /data/projects/ProjectA/fastq \
  -o project_name \
  -g /data/kpark-db/rnake/ecoli.fna \
  -a /data/kpark-db/rnake/ecoli.gff \
  -c 8 \
  -K

실행 예시

Go_Rnake.sh \
  -i RNake/20261001_RNA_HKP \
  -o RNake/20261001_RNA_HKP_out \
  -g "/data/kpark-db/rnake/ecoli.fna" \
  -a "/data/kpark-db/rnake/ecoli.gff" \
  -s "$KPARK_PIPELINES/RNake" \
  -K

전처리: fastp · 어댑터 제거 · 최소 길이 36 bp · 샘플별 HTML / JSON QC 보고서

옵션

옵션설명
-S no|yes|reverse라이브러리 strand 설정 · 기본값: no · 키트 프로토콜에 맞춰 지정
-n실행 계획 확인
-K오류 발생 시 나머지 샘플 계속 실행
-cSnakemake CPU 수
