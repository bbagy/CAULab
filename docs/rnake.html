RNake

세균 RNA-seq 리드의 트리밍, 참조 유전체 매핑, 유전자별 카운트 생성을 처리합니다. 샘플별 결과를 통합 카운트 표로 정리합니다.

STATUS: AVAILABLE — TESTED IN CORE3 WORKSTATION

분석 흐름

Prefilter→ Trim→ Bowtie2 Mapping→ Count Matrix→ Merged Table

컨테이너 빌드

cd RNake
docker build -t rnake:1.0 .

실행 방법

./RNake/Go_Rnake.sh \
  -i /path/to/reads \
  -o project_name \
  -g /path/to/genome.fna \
  -a /path/to/annotation.gff \
  -c 8 \
  -K

실행 예시

Go_Rnake.sh \
  -i RNake/20261101_RNA_HKP \
  -o RNake/20261101_RNA_HKP_out \
  -g /media/uhlemann/Core3_V2/REF/ecoli.fna \
  -a /media/uhlemann/Core3_V2/REF/ecoli.gff \
  -s "$CAULAB_PIPELINES/RNake" \
  -K

옵션

FlagDescription
