전사체

RNake

Bacterial RNA-seq · 트리밍 · 참조 유전체 매핑 · 유전자 카운트 · 샘플별 표 통합

설치 및 DB 준비 →

실행 환경: Docker / Apptainer

분석 흐름

Prefilter→ Trim→ Bowtie2 Mapping→ Count Matrix→ Merged Table

실행 방법

새 터미널 설정: source "$HOME/kpark-pipelines/kpark.env"

Go_Rnake.sh \
  -i /path/to/reads \
  -o project_name \
  -g /path/to/genome.fna \
  -a /path/to/annotation.gff \
  -c 8 \
  -K

실행 예시

Go_Rnake.sh \
  -i RNake/20261001_RNA_HKP \
  -o RNake/20261001_RNA_HKP_out \
  -g "$HOME/kpark-db/rnake/ecoli.fna" \
  -a "$HOME/kpark-db/rnake/ecoli.gff" \
  -s "$KPARK_PIPELINES/RNake" \
  -K

옵션

옵션설명
-n실행 계획 확인
-K오류 발생 시 나머지 샘플 계속 실행
-cSnakemake CPU 수

입력 구성

RNake/
|-- 20260901_RNA_HKP/
|-- 20260901_RNA_HKP_out/
|-- 20261001_RNA_HKP/
|   |-- SAMPLE1_R1.fastq.gz
|   `-- SAMPLE1_R2.fastq.gz
`-- 20261001_RNA_HKP_out/

$HOME/kpark-db/rnake/
|-- ecoli.fna
`-- ecoli.gff
