Installation

CAULab Setup

Install the pipeline family to a stable local directory; keep data and databases on a separate large disk.

git clone https://github.com/bbagy/CAULab.git
cd CAULab
./install_mac.sh --build-core
source "$HOME/caulab-pipelines/caulab.env"
caulab_usage.sh

Use --build-all for all container images. daDake2 uses host Snakemake, R/DADA2, and FIGARO.

Update

git pull
./install_mac.sh --update --build-core
source "$HOME/caulab-pipelines/caulab.env"

Local database settings in config/lab_paths.sh and config/lab_paths.yaml are preserved.
