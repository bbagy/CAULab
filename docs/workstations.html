설치와 업데이트

기본 설치 경로는 $HOME/caulab-pipelines입니다. 입력 데이터와 참조 DB는 설치 폴더 밖에 보관합니다.

1. 코드 다운로드와 설치

git clone https://github.com/bbagy/CAULab.git
cd CAULab
./install_mac.sh --build-core
source "$HOME/caulab-pipelines/caulab.env"
caulab_usage.sh

Docker를 실행한 상태에서 설치합니다. 모든 파이프라인 코드는 기본으로 복사되며, --build-core는 GoQC·KBracken·Humannake 이미지를 빌드합니다. 모든 컨테이너 이미지는 --build-all로 빌드할 수 있습니다.

2. 데이터베이스 준비

download_databases.sh --db-root /Volumes/CAULabDB --tools all --threads 8
source "$HOME/caulab-pipelines/caulab.env"

이 다운로드 명령은 숙주 필터링, Kraken2/Bracken, HUMAnN/MetaPhlAn DB를 준비합니다. 다른 파이프라인의 참조 자료는 각 도구 안내에 따라 준비하세요.

3. 기존 설치 업데이트

git pull --ff-only
./install_mac.sh --update --build-core
source "$HOME/caulab-pipelines/caulab.env"

업데이트해도 config/lab_paths.sh와 config/lab_paths.yaml의 로컬 DB 설정은 유지됩니다.

실행 환경 확인

  • 설치 위치를 바꾸려면 --prefix /path/to/caulab-pipelines를 사용하세요.
  • Apple Silicon에서 amd64 이미지가 필요하면 --platform linux/amd64를 지정하세요.
  • GoQC는 Docker로 실행합니다. daDake2는 호스트의 Snakemake·R/DADA2·FIGARO 환경이 필요합니다.
  • 처음 실행할 때는 각 도구의 dry-run 옵션으로 입력과 실행 계획을 확인하세요.
