1. screen — SSH 종료 후 작업 유지

긴 이미지 빌드·분석 작업을 SSH 연결 종료 후에도 유지하는 터미널 세션입니다. 서버 재부팅 시에는 종료됩니다.

설치

sudo apt update
sudo apt install -y screen
screen --version

세션 시작

kpark: 예시 세션 이름 · 프로젝트 이름 등으로 변경 가능

# 예시: kpark이라는 이름의 세션 생성
screen -S kpark

새 세션 안에서 실행

source "$HOME/kpark-pipelines/kpark.env"
# 여기에 이미지 빌드 또는 분석 명령 실행

세션 분리 / 재접속

작업명령 / 키
분리 · 작업 유지Ctrl + a, 손을 뗀 뒤 d
세션 목록screen -ls
재접속screen -r kpark
기존 연결 분리 후 재접속screen -d -r kpark
실행 중 명령 중지Ctrl + c
작업 완료 후 세션 종료exit
screen -ls
screen -r kpark

재접속: 생성할 때 지정한 세션 이름 사용
분리: Ctrl+a → d · Ctrl+c는 작업 중지
새 세션 이름: screen -S ProjectA

2. crontab — 예약 실행

서버 시간 기준 반복 실행입니다. 등록한 사용자 권한으로 실행하며, 터미널의 PATH·Conda 활성화 설정은 자동으로 적용되지 않습니다.

설치 / 서비스 확인

sudo apt install -y cron
sudo systemctl enable --now cron
systemctl is-active cron
timedatectl

시간 형식

# 분   시   일   월   요일   명령
# 0-59 0-23 1-31 1-12 0-7    (요일: 0/7 일요일)
예약시간 필드
매일 09:000 9 * * *
매주 월요일 09:000 9 * * 1
30분마다*/30 * * * *

예시: 디스크 사용량 기록

터미널에서 로그 폴더 준비

mkdir -p "$HOME/kpark-logs"
crontab -e

열린 crontab 편집기에 아래 두 줄 추가 · 저장 후 종료

SHELL=/bin/bash
0 9 * * * { date; df -h "$HOME"; } >> "$HOME/kpark-logs/disk.log" 2>&1

예약 확인 / 로그 확인

crontab -l
tail -n 30 "$HOME/kpark-logs/disk.log"

분석 스크립트 예약 시

스크립트 내부: source "$HOME/kpark-pipelines/kpark.env"
daDake2: Conda 초기화 + 환경 활성화 추가
경로: 절대 경로 · 로그: >> LOG_FILE 2>&1
반복 분석 중복 실행 방지: flock -n
예약 해제: crontab -e에서 해당 줄 삭제 또는 앞에 # 추가

3. 로그 / 서버 상태

로그 실시간 확인

tail -f "$HOME/kpark-logs/disk.log"

Ctrl+c: 로그 보기 종료 · 분석 작업 유지

디스크 / 메모리 / 프로세스

df -h
free -h
top

top 종료: q

명령 실행 로그 저장

# 실제 스크립트 경로로 변경
bash /path/to/run_analysis.sh > "$HOME/kpark-logs/analysis.log" 2>&1
