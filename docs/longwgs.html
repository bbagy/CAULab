longWGS

ONT Bacterial Genome · 조립 · 오류 교정 · 품질 평가 · 유전체 주석

설치 및 DB 준비 →

STATUS: TESTED IN NOOK AND CORE3 WORKSTATION

분석 흐름

barcode dirs→ Go_merge_rename.sh→ sample.fastq.gz→ Prefilter→ QC / Porechop→ Autocycler→ dnaapler + metrics→ Medaka→ QUAST + CheckM2→ Coverage→ Kraken2→ Bakta

전처리: 병합과 이름 정리

ONT barcode별 FASTQ → Go_merge_rename.sh로 병합 / 샘플명 변경

샘플 매핑 파일: 탭 / 공백 구분

KP0011  barcode01
KP0063  barcode02
...
# dry-run first
bash Go_merge_rename.sh -i fastq_pass -o merged_fastqs -m samples_barcodes.txt -n

# apply
bash Go_merge_rename.sh -i fastq_pass -o merged_fastqs -m samples_barcodes.txt

분석 입력: -i merged_fastqs/

실행 방법

새 터미널 설정: source "$HOME/caulab-pipelines/caulab.env"

Go_longWGS.sh \
  -i /path/to/fastq \
  -o /path/to/output \
  -d /path/to/db \
  -M strict \
  -K

실패 단계 처리

# default: stop on stage failures
Go_longWGS.sh -i IN -o OUT -d DB -M strict -K

# continue to summary Excel even if some Bakta jobs fail
Go_longWGS.sh -i IN -o OUT -d DB -M permissive -K

permissive: Bakta 실패 샘플 기록 후 가용 결과로 요약 생성
실패 기록: 0_failed_samples.tsv · 7_bakta/<sample>/FAILED.txt

실행 예시

Go_longWGS.sh \
  -i longWGS/20261001_ONT_HKP \
  -o longWGS/20261001_ONT_HKP_out \
  -d /media/uhlemann/core4/DB/longWGS_DB \
  -s "$CAULAB_PIPELINES/longWGS" \
  -M strict \
  -p 0 \
  -K

옵션

옵션설명
-n실행 계획 확인
-K오류 발생 시 나머지 샘플 계속 실행
-M strict|permissive실패 처리 방식
-p 0|1Porechop 미사용 / 사용
-s사용자 지정 Snakefile 폴더
