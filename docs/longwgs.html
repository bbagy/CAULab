longWGS

ONT 세균 유전체 분석. 조립, 오류 교정, 품질 평가, 유전체 주석을 수행합니다.

참조 DB 준비 ↓

STATUS: TESTED IN NOOK AND CORE3 WORKSTATION

분석 흐름

barcode dirs→ Go_merge_rename.sh→ sample.fastq.gz→ Prefilter→ QC / Porechop→ Autocycler→ dnaapler + metrics→ Medaka→ QUAST + CheckM2→ Coverage→ Kraken2→ Bakta

컨테이너 빌드

cd longWGS
docker build -t longwgs .

전처리: 병합과 이름 정리

ONT output produces per-barcode directories. Before running the pipeline, merge reads and rename to sample names using Go_merge_rename.sh.

Map file format (tab or space separated):

KP0011  barcode01
KP0063  barcode02
...
# dry-run first
bash Go_merge_rename.sh -i fastq_pass -o merged_fastqs -m samples_barcodes.txt -n

# apply
bash Go_merge_rename.sh -i fastq_pass -o merged_fastqs -m samples_barcodes.txt

Then use merged_fastqs/ as the -i input for the pipeline.

실행 방법

./longWGS/Go_longWGS_V1_1.sh \
  -i /path/to/fastq \
  -o /path/to/output \
  -d /path/to/db \
  -M strict \
  -K

실패 단계 처리

# default: stop on stage failures
./longWGS/Go_longWGS_V1_1.sh -i IN -o OUT -d DB -M strict -K

# continue to summary Excel even if some Bakta jobs fail
./longWGS/Go_longWGS_V1_1.sh -i IN -o OUT -d DB -M permissive -K

In permissive mode, failed Bakta samples are recorded in 0_failed_samples.tsv and 7_bakta/<sample>/FAILED.txt, while the final summary workbook is still generated from available outputs.

실행 예시

Go_longWGS.sh \
  -i longWGS/20261101_ONT_HKP \
  -o longWGS/20261101_ONT_HKP_out \
  -d /media/uhlemann/core4/DB/longWGS_DB \
  -s "$CAULAB_PIPELINES/longWGS" \
  -M strict \
  -p 0 \
  -K

옵션

FlagDescription
-nDry-run
-KKeep-going
-M strict|permissiveFailure handling mode
-p 0|1Porechop off/on
-sCustom snakefile directory

Medaka 모델 캐시LONG_DB/medaka_models/
LONG_DB="/path/to/longWGS_DB"
mkdir -p "$LONG_DB/medaka_models"
docker run --rm -v "$LONG_DB":/db longwgs bakta_db download --output /db --type full
# 최초 설치: 다운로드된 db 폴더를 파이프라인 이름에 맞춥니다.
mv "$LONG_DB/db" "$LONG_DB/bakta_DB"
docker run --rm -v "$LONG_DB":/db longwgs micromamba run -n checkm2_110 checkm2 database --download --path /db
docker run --rm -v "$LONG_DB":/db longwgs plassembler download -d /db/plassembler_db

longwgs 이미지를 먼저 빌드합니다. CheckM2 DB는 이미지에 설치된 1.1.0용으로 받으며, CheckM1 DB로 대체할 수 없습니다. Medaka 모델은 사용한 basecaller 모델에 맞춰 선택하며 캐시 폴더를 유지합니다.

Kraken2는 공식 DB 목록 ↗에서 필요한 아카이브를 받아 LONG_DB/kraken2DB/에 풉니다. 이 폴더 바로 아래에 hash.k2d, opts.k2d, taxo.k2d가 있어야 합니다. 다른 폴더를 가리키는 링크는 컨테이너에서도 접근 가능한 경로여야 합니다. 실행에는 -d "$LONG_DB"를 사용합니다.
