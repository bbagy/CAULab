실행 방법

# 16S V3V4 — multiple projects
DB="/media/uhlemann/core4/DB/DADA2/Bacteria/silva_nr99_v138.1_wSpecies_train_set.fa.gz"
dirs="ProjA,ProjB,ProjC"
smk="$CAULAB_PIPELINES/daDake2"

Go_daDake2.sh -t standard_V3V4 -i $dirs -d $DB -s $smk -c 8 -K
# Zymo V1V2
Go_daDake2.sh -t zymo_V1V2 -i "ProjA,ProjB" -d $DB -s $smk -c 8 -K
# ITS
DB_ITS="/media/uhlemann/core4/DB/DADA2/Fungi/sh_general_release_dynamic_29.11.2022.fasta"
Go_daDake2.sh -t illumina_ITS -i "ProjA,ProjB" -d $DB_ITS -s $smk -c 8 -K
# dry-run
Go_daDake2.sh -t standard_V3V4 -i "ProjA" -d $DB -s $smk -n

옵션

FlagDefaultDescription
-t—standard_V3V4 | zymo_V1V2 | illumina_ITS
-i—Comma-separated project directories (no spaces)
-d—Taxonomy DB path (SILVA or UNITE .fa.gz)
-sscript dirDirectory containing Go_daDake2.smk (use when running via symlink)
-c4Snakemake cores
-m10000Min FASTQ size in bytes (smaller → failed.csv)
-noffDry-run
-KoffKeep going on sample failure

실행 시 참고 사항

  • 파일 날짜: 실행 시점 yymmdd · 날짜별 출력 분리
  • -m 미만 샘플: failed.csv 기록
  • 필터 후 0 reads: failed.csv 기록 · 후속 단계 제외
  • 16S 전용 제거: NA phylum · Chloroplast · Mitochondria
  • addSpecies(): 미사용 · species DB 불필요
  • 16S 매핑 템플릿: 3_map/
  • 계통수 환경: qiime2
  • 잠금 오류: --unlock 후 자동 재시도
