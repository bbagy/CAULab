daDake2

설치 및 DB 준비 →

지원 데이터

분석 유형영역프라이머 제거Off-target 제거
standard_V3V416S V3–V4trimLeft만 사용적용 (NA phylum · Chloroplast · Mitochondria)

Paired FASTQ→ [ITS] cutadapt→ filterAndTrim→ learnErrors→ dada + merge→ chimera removal→ assignTaxonomy→ phyloseq + CSV→ qiime2 tree

cutadapt: illumina_ITS 전용

실행 방법

UNITE: General FASTA · All eukaryotes 다운로드 ↗
예시 경로: 받은 파일을 $HOME/kpark-db/dadake2/unite_general.fasta로 저장 · 배포 버전 / 날짜 기록
DB 형식: FASTA 또는 gzip 압축 FASTA

# 16S V3V4 — multiple projects
DB="$HOME/kpark-db/dadake2/silva_nr99_v138.1_wSpecies_train_set.fa.gz"
dirs="ProjA,ProjB,ProjC"
smk="$KPARK_PIPELINES/daDake2"

Go_daDake2.sh -t standard_V3V4 -i $dirs -d $DB -s $smk -c 8 -K
# Zymo V1V2
Go_daDake2.sh -t zymo_V1V2 -i "ProjA,ProjB" -d $DB -s $smk -c 8 -K
# ITS
DB_ITS="$HOME/kpark-db/dadake2/unite_general.fasta"
Go_daDake2.sh -t illumina_ITS -i "ProjA,ProjB" -d $DB_ITS -s $smk -c 8 -K
# dry-run
Go_daDake2.sh -t standard_V3V4 -i "ProjA" -d $DB -s $smk -n

옵션

옵션기본값설명
-t—standard_V3V4 | zymo_V1V2 | illumina_ITS
-i—프로젝트 폴더 목록 · 쉼표 구분 · 공백 제외
-d—분류 DB 경로 · SILVA / UNITE FASTA (.fa / .fasta / .fa.gz / .fasta.gz)
-s실행 스크립트 폴더Go_daDake2.smk 위치 · 심볼릭 링크 실행 시 지정
-c4Snakemake CPU 수
-m10000FASTQ 최소 크기 (bytes) · 미만 샘플: failed.csv
-n미사용실행 계획 확인
-K미사용샘플 실패 시 나머지 샘플 계속 실행

실행 시 참고 사항

  • 파일 날짜: 실행 시점 yymmdd · 날짜별 출력 분리
  • -m 미만 샘플: failed.csv 기록
  • 필터 후 0 reads: failed.csv 기록 · 후속 단계 제외
  • 16S Off-target 제거: NA phylum · Chloroplast · Mitochondria
  • addSpecies(): 미사용 · species DB 불필요
  • 16S 매핑 템플릿: 3_map/
  • 계통수 환경: qiime2
  • 잠금 오류: --unlock 후 자동 재시도
