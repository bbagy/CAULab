GoQC

Paired-end FASTQ quality control and host read depletion with fastp and Bowtie2.

source "$HOME/caulab-pipelines/caulab.env"
Go_QC.sh -i /path/to/raw_fastq -o /path/to/output/ProjectA_QC -c 8 -j 4 -K

Configure CAULAB_HOST_BT2_PREFIX in config/lab_paths.sh, or pass -d /path/to/host_index.

Docker image: goqc:caulab. Downstream input: host_filtered_fastq/.
