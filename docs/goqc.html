GoQC

Paired-end FASTQ 전처리. fastp로 저품질 리드를 정리하고 Bowtie2로 숙주 리드를 제거합니다.

참조 DB 준비 ↓

source "$HOME/caulab-pipelines/caulab.env"
Go_QC.sh -i /path/to/raw_fastq -o /path/to/output/ProjectA_QC -c 8 -j 4 -K

Configure CAULAB_HOST_BT2_PREFIX in config/lab_paths.sh, or pass -d /path/to/host_index.

Docker image: goqc:caulab. Downstream input: host_filtered_fastq/.

Full GoQC guide

DB / 참조 파일저장 위치 · 실행 옵션

source "$HOME/caulab-pipelines/caulab.env"
DB_ROOT="/path/to/DB"
bash "$CAULAB_PIPELINES/download_databases.sh" --db-root "$DB_ROOT" --tools host
source "$CAULAB_PIPELINES/config/lab_paths.sh"

Docker 이미지 goqc:caulab를 먼저 빌드합니다. 다운로드 후 설정 파일에 숙주 인덱스 경로가 기록됩니다. -d에는 폴더가 아닌 인덱스 접두어를 지정합니다. 사람 이외의 숙주라면 해당 종의 FASTA로 Bowtie2 인덱스를 별도로 만듭니다.
